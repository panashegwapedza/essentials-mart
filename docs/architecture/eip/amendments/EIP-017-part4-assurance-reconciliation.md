# EIP-017 Reconciliation — External Partner Adapter Gateway

**Status:** Applied / Reconciled  
**Date:** 2026-08-22

EIP-017 remains the reusable provider-neutral external partner adapter/gateway pattern.

Its implementation must satisfy the Part 4 defensive baseline for authentication, authorisation, rate limiting, abuse detection, replay protection, monitoring, incident response, resilience, partner substitution, IP protection and assurance.

This is an implementation constraint, not a change to the adapter pattern.

**Resolves GAP-010.**
