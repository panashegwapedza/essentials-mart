# EIP-018 Reconciliation — Resource-Aware Multimodal Delivery Orchestration

**Status:** Applied / Reconciled  
**Date:** 2026-08-22

EIP-018 remains the reusable delivery orchestration pattern for scheduled, shared, personalised, express and other authorised delivery modes.

Its implementation must satisfy Part 4 requirements for API security, partner/provider boundaries, economic-abuse prevention, trust, monitoring, containment, incident response, resilience, global defensive scalability and assurance.

The orchestration engine remains resource-aware and must not bypass customer authority or domain ownership.

**Resolves GAP-011.**
